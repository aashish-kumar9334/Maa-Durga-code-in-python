# 🌺 Maa Durga Drawing Using Python Turtle Graphics 🕉️

A beautiful digital artwork of **Maa Durga** created using Python's built-in `turtle` graphics module. This project uses colorful shapes, geometric patterns, circles, and lines to draw Maa Durga with a golden crown, divine third eye, traditional jewelry, red saree, Trishul, lotus, and decorative diyas.

## ⚙️ Prerequisites

Before running the project, make sure you have:

* Python 3 installed on your computer
* A graphical desktop environment that supports Turtle graphics

The `turtle` and `math` modules are included with standard Python installations in most environments.

## 🚀 How to Run the Project

**Step 1: Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Maa-Durga-Turtle-Art.git
```

**Step 2: Navigate to the project folder**

```bash
cd Maa-Durga-Turtle-Art
```

**Step 3: Run the Python program**

```bash
python maa_durga.py
```

On some systems, you may need to use:

```bash
python3 maa_durga.py
```

A Turtle graphics window will open and display the Maa Durga artwork.

## 📌 Key Functions

| Function                         | Purpose                          |
| -------------------------------- | -------------------------------- |
| `move(x, y)`                     | Moves the turtle to a coordinate |
| `filled_circle(x, y, r, color)`  | Draws a filled circle            |
| `polygon(points, color)`         | Draws a filled polygon           |
| `line(points, color, width)`     | Draws connected lines            |
| `write(x, y, text, size, color)` | Displays text on the screen      |
